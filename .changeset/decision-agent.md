决策代理人：观察者建完卡后另跑一个无工具会话，对这批卡出「票拟」——2–3 个方案，各写成本、长期收益（以后每次少走几步）、最坏情况，并给出一句采纳后回给原会话的话。代理人不执行任何动作，只写 `card.advice`，另外允许把错标成「要我决策」的事实卡降级为「要我知晓」。

配套：判例库 `precedents.json`（作答 / 完成 / 忽略 / 采纳 / 聊天作答都落一条，返工过的判例不再进决策输入）、`/decisions` 端点、`adopt` 与 `mark-reworked` 两个动作，以及面板上的票拟 chip、方案对照、一键采纳与返工标记。

默认提示词写的是用户本人的决策画像（中长期优先、方案第一项必须是最小可验证一步、长期收益按省下的步骤数计、试错期不沉淀、判例优先），见 `src/host/decision/defaults.ts` 与 `docs/decision-agent.md`。
